# Example token setups

Hands-on playgrounds for Token Atlas — one folder per token architecture seen in the wild. Open this repo (or any one folder) in VS Code with Token Atlas installed and poke at them.

| Folder             | Architecture                                                       | Try this                                                                                                                                                                                                          |
| ------------------ | ------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `01-single-file`   | Everything in one flat `tokens.json`                               | Hover colors (swatch, HEX and OKLCH, contrast on white and black) and dimensions (PX · REM · PT)                                                                                                                  |
| `02-tiered`        | Primitive → semantic → component layers in one file                | Hover `component.button.background` — the chain resolves three hops; Cmd+click any `{alias}`                                                                                                                      |
| `03-by-category`   | One file per category, references across files                     | Hover `type.link-color` — source file is listed; completion inside a `$value` offers tokens from the sibling files                                                                                                |
| `04-theming`       | Shared primitives + `light` / `dark` theme files                   | The same `theme.background` path resolves to different colors per file; Cmd+click jumps into `primitives.tokens.json`                                                                                             |
| `05-multi-brand`   | Two brands defining identical token paths                          | Each brand's `brand.primary` resolves to its **own** accent — local file wins over the workspace                                                                                                                  |
| `06-tokens-studio` | Tokens Studio-style export (`$themes`, `$metadata`)                | The themes are offered in the active-set picker; each resolves against the sets it enables                                                                                                                        |
| `07-kitchen-sink`  | Every DTCG type + deliberate mistakes                              | One token of every type for hover-testing; the `broken` group lights up the Problems panel (cycle, dangling ref)                                                                                                  |
| `08-exported-code` | Tokens plus the CSS / Sass / TS an export tool emits               | Hover `--color-blue-500`, `$space-sm`, or `tokens.space.md` in the code files — same card as the JSON; Cmd+click jumps to the token                                                                               |
| `09-resolver`      | A DTCG resolver document composing base, theme and component files | Click the token set in the status bar and pick _Example app — theme: darkHighContrast_; hover `page.text` in `components.tokens.json` — high-contrast overrides dark                                              |
| `10-extends-ref`   | Component variants built with `$extends` and `$ref` JSON Pointers  | Hover `{button-large.text}` in `caption` — inherited through two `$extends` from `button` in `base.tokens.json`; Cmd+click jumps there. Hover `focus.ring` — its components come from `color.blue` through `$ref` |

Notes: files are named `*.tokens.json` (or `tokens.json`) so they match Token Atlas's default `tokenAtlas.include` globs for cross-file indexing — language features themselves are content-based and work under any name. The visual editor is available on any of these via right-click → _Reopen Editor With… → Token Editor_.
